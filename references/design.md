# Design & Touch Notes

目标：Windows 10 + Edge + 3840×2160 希沃触摸大屏，主要用**手指**操作。页面必须在 3 米左右可读，不能是桌面版缩小。

## 1. 视觉方向

参考 Claude Help Center / Claude 品牌页的编辑式气质，但不复制其商业字体：

- 暖白纸感背景：`#faf9f5`
- 深墨正文：`#141413`
- 珊瑚色强调：`#cc785c`，深色 `#a9583e`
- 暖灰边框：`#e6dfd8`
- 8–14px 圆角，细边框，轻阴影
- 英文原文用衬线字体，中文 UI 用无衬线
- 大留白，少卡片，少装饰
- 不用重阴影、玻璃拟态、渐变背景、复杂动效

字体栈（离线、系统回退）：

```css
--serif: "Source Serif 4", "Iowan Old Style", "Palatino Linotype",
         "Book Antiqua", Georgia, "Songti SC", "SimSun", serif;
--ui: "Inter", "Segoe UI", "Microsoft YaHei", "PingFang SC",
      system-ui, sans-serif;
```

不要打包 Copernicus/StyreneB。需要更接近时，可内嵌 Source Serif 4 / Inter 的 WOFF2 子集，但必须仍然离线、单文件。

## 2. 布局

### 4K 横向

```text
┌ 顶部：品牌 / 题型下拉框 / 文章标题 + 页码/词数/题数 / 字号 / 全屏 / 重置 ┐
├ 图例：依据 / 关键词 / 空格 / 生词 / 长难句 ┤
├──────────────────────────┬──────────────────────────────┤
│ 原文（独立滚动）          │ 解析（独立滚动）              │
│ 约 72ch，衬线             │ 52rem 宽，题目卡片            │
└──────────────────────────┴──────────────────────────────┘
```

- 题型切换用顶部下拉框，不再使用横向 tab；页面不保留单独的题型导航行。
- 右栏设“解析 / 词汇 / 结构 / 考点”四个下划线选项卡；结构内含结构图、主旨链、一句话主旨，考点独立成页。
- 选项卡无边框、无实心底、无圆角；选中为珊瑚色粗体 + 3px 底部下划线，未选中 #666；`:active` 用 paper-deep 浅灰反馈。
- 结构节点、主旨链、考点卡都带原文锚点；点击后左侧原文滚动到对应段落并高亮。
- 字号选中态用珊瑚色，不用黑色。
- 顶栏为单行四区块：文章信息（主/副标题两行）→ 题型下拉 → 图例（3+2 两行网格）→ 右侧操作区。
- 文章信息用 flex column 左对齐：主标题 22px 加粗，副标题 14px 浅灰；不再使用 Logo。
- 图例用 3 列网格，第一行 3 个、第二行 2 个；小号灰色“?”放在第二行最后。
- 右侧字号分段、全屏、重置保持一行，按钮 40–48px 高；整行 align-items:center。
- 顶栏使用 flex + space-between + nowrap；区块 gap 约 24–32px。
- 两栏默认约 56/44，中间有可拖拽控制杆。
- 左右各自滚动，`overscroll-behavior: contain`。
- 顶部不随内容滚动；切换题型时，顶部上下文随 section 更新。
- 顶部不再放“样卷/页码来源”或全局“AI 推断”徽章；答案来源在每题卡片上标注。
- 原文/解析不要外框，不铺卡片底；直接坐在暖白页面上，用控制杆分隔。
- 原文/解析两栏都可触摸滚动；`touch-action: pan-y` + `overflow:auto`，Edge 原生惯性，不拦截 `touchmove`。
- 右栏结构/考点面板、词汇表、抽屉、题号索引也都要设置 `-webkit-overflow-scrolling: touch` / `touch-action`。
- 控制杆拖到 ≥80% 自动收起解析，拖到 ≤20% 自动收起原文；收起后侧边显示竖排“解析/原文”按钮。
- 窄屏（≤1150px）改为单栏，解析接在原文后。
- 手机（≤760px）进一步缩小字号，抽屉改为底部。

### 字号

```css
--base-fs: clamp(20px, 0.8vw, 32px);
```

- 4K 100%：约 30.7px；1080p：20px。
- 正文 1.07rem，行高 1.85。
- 4K 约 33px，3 米可读；1080p 约 21px。
- 字号切换：标准 / 大（×1.1）/ 特大（×1.22），用 CSS 变量整体缩放。

## 3. 触摸热区

底线：**56px**。常用操作 64–92px。

| 元素 | 4K | 1080p |
|---|---:|---:|
| 题型切换 | 92 | 56 |
| 选项整行 | 108 | 67 |
| 题号 chip | 72 | 56 |
| 七选五选项 | 96 | 60+ |
| 空格（视觉/热区） | 57 / 77 | 37 / 57 |
| 长难句“析” | 56 | 40（整句也可点） |
| 分栏控制杆 | 56 | 46 |
| 右栏下划线选项卡 | 48 | 55 |
| 结构节点/主旨链/考点卡 | 56+ | 56+ |
| 关闭按钮 | 92 | 56 |
| 详情抽屉按钮 | 92 | 56 |

- 选项不是只有字母可点，整行可点。
- 行内空格的视觉可以小于 56px，但用 `::before` 把热区扩到 56px 以上。
- 相邻可点元素间距至少 8–12px。
- 不要出现只有 hover 才能看到的信息。

## 4. 交互

### 鼠标

- hover 选项：预览原文证据；
- hover 生词：小悬浮卡（音标、词性、语境义）；
- hover “析”：小悬浮卡（主句 + 翻译）；
- 点击：固定/打开完整抽屉。

### 手指

- 中英对照默认开启，按钮可切“中英/仅英文”；每段英文下方跟中文，长难句/关键句另有翻译；
- 点题号旁“显示答案”：才显示答案、证据、选项判断；未点击时这些内容全部隐藏；
- 未显示答案时点选项只表示“我选了这个”，不能高亮原文证据；
- 七选五选项库只展示 A–G 文本，不显示答案映射标签；
- 点生词：右侧大抽屉（词汇、搭配、例句、本文语境）；
- 点“析”或长难句：右侧大抽屉（主句、层次、翻译）；
- 点右栏“词汇”中的词：右侧大抽屉（音标、词性、释义、搭配、例句、相关高考考点）；
- 点空格：跳到对应题卡；完形/七选五同时激活正确选项；
- 点七选五选项：跳到它对应的空格；
- 点遮罩 / 关闭 / Esc：关闭抽屉。

### 错误选项

如果某个错误选项没有直接的反驳句：

- 用浅色（fallback）显示正确项的关键依据；
- 显示提示：“该选项在原文中没有直接依据；下面以浅色显示本题正确项的关键依据。”
- 不要清空高亮让用户以为“没反应”。

## 5. 颜色语义

- 黄色：答案依据；
- 关键词：珊瑚色方括号 `[ ]`（不是彩色下划线）；
- 长难句：Office 式黄色矩形高亮（无圆角）+ 方形“析”；
- 空格：珊瑚色虚线框；
- 生词：灰色点线下划线；
- 珊瑚色：空格、答案、当前选中、关键词括号；
- 关系类型：放在链接 chip 的标签里（同义/改写/反义/逻辑/搭配/推断）。

颜色不能作为唯一信息：证据框有“原文依据”标签，选项有“答案/定位”，图例始终可见。

## 6. 组件细节

- `.q-card`：1px 暖灰边框，激活时珊瑚色柔光。
- `.q-reveal`：题号旁“显示答案/隐藏答案”按钮，56px+ 高；未展开时隐藏答案区。
- `.lang-toggle`：原文栏“中英/仅英文”切换，56px+ 高。
- `.analysis-tabs` / `.tab-btn`：右栏四个选项卡，56px+ 高。
- `.structure-flow` / `.idea-chain` / `.exam-card.is-link`：结构图、主旨链、考点卡，均带 `data-blocks` 锚点。
- `.zh`：中文对照行，英文段落后显示，字号略小、左侧珊瑚细线。
- `.evidence-trans`：答案展开后的关键句翻译。
- `.option`：整行按钮，左侧字母块，右侧“答案/定位”。
- `.evidence-box`：左侧金色 3px 竖线，浅暖底。
- 原文答案依据 `.ev`：点“显示答案”后先滚动到所在段落；滚动停止后，内联背景以 `background-size: 0% → 100%` 在 500ms 内从左向右展开。用 `box-decoration-break: clone` 处理多行，不使用绝对定位；动画结束后 `.is-on` 与 `.ev-wipe` 保留，不自动消失。
- `.tab-panel` / `.vocab-list`：右栏词汇/结构/考点内容；只显示当前篇，行内是 word / IPA / POS / 中文，不写题号。
- `.splitter`：原文与解析之间的拖拽杆；4K 宽 56px，1080p 46px。
- `.link-chip`：关系标签 + 选项短语 ↔ 原文短语，可点跳转。
- `.bank`：七选五 A–G 两列，显示“→ 题号”或“干扰项”。
- `.q-index`：横向滚动，不换行；15 个完形题号也不会挤成两行。
- `.drawer`：右侧 900px 宽，4K 下大字号；窄屏底部 82dvh。
- `.toast`：底部居中，深墨底，短暂提示。

## 7. 单文件

- CSS/JS/JSON 全部内联；
- 图片图表用 `data:image/...`；
- 无 CDN、无外部字体请求；
- `file://` 直接打开可运行；
- 目标浏览器 Edge/Chromium，不需要兼容旧 IE。

## 8. 验收尺寸

- 3840×2160：无横向滚动；正文 ≥30px；选项 ≥108px。
- 1920×1080：无横向滚动；正文 ≥20px；选项 ≥64px。
- 浏览器缩放 125%/150%：不溢出、不遮挡。
- 手指点选一次命中；滚动不误触。
- 抽屉打开后背景不滚动；关闭后焦点回到触发元素。
