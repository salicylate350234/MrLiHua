# Analysis Rubric

## 0. 先解决答案，再写解析

顺序不能反：

1. 有答案页：先录入答案；
2. 没有答案页：先独立做题，写下答案与置信度；
3. 再逐选项找依据；
4. 最后写错因与方法。

不要把“解析”写成对答案的事后合理化。每个答案都要能回到原文的具体句子。

## 1. 证据（evidence）

每个选项最好有一条明确依据；至少正确项必须有。

- `quote` 必须是原文精确子串，不要改写、不要合并两段；
- 一条 evidence 最好是一句话或一个完整分句；
- 用 `supports` 标记它支持哪些选项；
- 用 `refutes` 标记它与哪些选项冲突；
- 没有直接依据时，不要硬造 quote；在 `optionNotes` 里说明“无直接依据/需推断”。

### 证据优先级

1. 直接复现题干关键词的句子；
2. 同义改写句；
3. 段落主题句/结论句；
4. 上下文逻辑句（转折、因果、举例）；
5. 全文结构/语气（用于主旨、标题、态度题）。

## 2. 选项分析

每个选项都要有判断：

- 正确项：定位 + 同义/改写关系 + 为什么其他项不对；
- 干扰项：具体错因，不能只写“与原文不符”。

错因分类：

- 偷换概念：把 A 说成 B；
- 范围扩大/缩小：all/only/must/never；
- 无中生有：原文没有的信息；
- 张冠李戴：把甲的特征套到乙；
- 反向关系：把因果、利弊、态度说反；
- 程度不当：原文 possible，选项 certain；
- 时态/主体错误：时态、动作发出者不对；
- 以偏概全：用一个细节代替全文。

## 3. 关系类型

只使用以下类型，不要发明新标签：

| type | 用途 | 例子 |
|---|---|---|
| `synonym` | 同义词/近义词 | dominated ↔ took control of |
| `paraphrase` | 句式改写/语义转述 | was unwilling ↔ reluctant |
| `antonym` | 反义/转折/对比 | stable ↔ change daily |
| `logic` | 逻辑衔接 | However ↔ 对比 |
| `collocation` | 固定搭配 | take a toll on |
| `inference` | 需要一步推断 | 海外校区 → 模式被复制 |
| `reference` | 代词/指代 | they → tourists |

原则：

- 没有明确关系就不要写；
- 不要把“同一话题”写成“同义”；
- `sourcePhrase` 与 `optionPhrase` 都要能在文本中找到；
- 多个片段用 ` ... ` 分隔，每段都必须能定位。

## 4. 题型差异化

### 阅读 A–D

- 细节题：题干关键词 → 原文句 → 同义替换；
- 推断题：原文事实 → 一步推理 → 不能过度；
- 主旨/标题：覆盖全文，不能只覆盖一段；
- 词义猜测：搭配 + 上下文情感色彩；
- 态度题：评价性形容词/副词 + 让步主句；
- 来源题：结构、语气、内容功能，不靠个别词。

### 七选五

看四类线索：

1. 代词指代：it/they/this/these/such；
2. 词汇复现：同词、同义、反义；
3. 逻辑连接：however/therefore/also/for example；
4. 段落功能：总起、举例、转折、结论。

同时看空前和空后；选项中的“also/both/another”往往需要前文有对应项。

### 完形

四个维度：

- 上下文逻辑：转折、因果、让步、并列；
- 固定搭配：动词+介词、名词+介词；
- 语义场：同主题词；
- 语法限制：时态、单复数、词性。

先读全句，再读前后句；不要只看空格所在短语。

### 语法填空

- 有提示词：词性转换、时态/语态、非谓语、比较级；
- 无提示词：冠词、介词、连词、代词；
- 先判断空格在句中的成分，再判断形式；
- 解析写“考点 + 线索 + 规则 + 翻译”；
- 多解时在 `rule` 里说明，但 `answer` 只填首选。

## 5. 词汇

每篇 8–12 个，优先：

- 高考 3500 之外、但文中承担关键语义的词；
- 熟词僻义；
- 动词短语/固定搭配；
- 抽象名词、态度形容词；
- 易混词。

不要标：

- 专有名词（人名、地名、机构名）；
- 仅因大小写/复数变化的简单词；
- 已在本篇多次注释的词。

字段：音标、词性、语境义、搭配、例句、`core/beyond`。

## 6. 长难句

筛选：

- 约 25 词以上；
- 或含 2 个以上从句/非谓语/插入语/倒装/省略；
- 或直接影响主旨/题目理解。

每篇 2–4 句。结构写：

1. 主句骨架；
2. 从句层级；
3. 非谓语/插入语/修饰成分；
4. 指代；
5. 中文翻译。

翻译要通顺，不要逐词硬译；结构分析要能解释“为什么这样翻”。

## 7. 置信度

- 0.95–0.99：原文直接对应/规则明确；
- 0.85–0.94：需要一步推断/语篇归纳；
- 0.70–0.84：两个选项都可能，需说明；
- < 0.70：标“待核对”，不要装确定。

## 8. 不要做的事

- 不查试卷来源、地区、年级、学校；
- 不搜索公开答案；
- 不把推断写成官方答案；
- 不为了页面好看编造同义词；
- 不把“段落提到”当成“全文主旨”；
- 不在没有原文依据时写 quote。
